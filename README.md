
# SkillMatch AI 

**Персональный карьерный ассистент портала «People»**

---

##  О проекте

**SkillMatch AI**— это надстройка над карточкой вакансии, которая превращает пассивный просмотр в интерактивную карьерную консультацию. Система анализирует три вектора данных: профиль соискателя, требования вакансии и поведенческую историю пользователя.

###  Проблематика

Соискатели сталкиваются с:
- Неопределённостью («подхожу ли я?»)
- Отсутствием обратной связи на этапе просмотра вакансии
- Высоким процентом отказов от отклика
- Подачей нерелевантных резюме «на удачу»

**Решение:** снять психологический барьер и предоставить кандидату объективный вектор развития внутри экосистемы банка.

---

##  Ключевой функционал

### Match Score
Количественная оценка релевантности профиля кандидата требованиям вакансии.

###  Радар компетенций
Визуализация сильных сторон и зон роста по 5 осям:
- Hard Skills
- Опыт работы
- Код
- Архитектура
- Soft Skills

###  Skill Mapping
Автоматическое выделение ключевых тегов:
- Зеленые - Совпадающие навыки
- Красные - Отсутствующие навыки

###  Персонализированный фидбек
Текстовое обоснование оценки без использования шаблонных фраз.

###  Интеграция с Habr
Динамические рекомендации статей из блога «Совкомбанк Технологии» для устранения выявленных пробелов в знаниях.

###  Карьерный маршрут
Пошаговый план развития для достижения требований данной вакансии.

###  Работа с поведенческими триггерами
Использование данных из датасета `actions_history` для выявления скрытого интереса. При повторных просмотрах без отклика ИИ генерирует специфический Call-to-Action.

##  Архитектура и безопасность

###  Grounding Method
Промпт-инжиниринг ограничивает область знаний модели **только предоставленными данными**.

###  Structured Output
Использование **JSON-mode** для передачи данных от LLM гарантирует корректность отображения графиков и тегов в интерфейсе.

###  Data Privacy
Отсутствие использования реальных персональных данных.

##  Быстрый старт

### Предварительные требования
- Docker и Docker Compose
- API-ключ OpenRouter

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/FedorGutsch/scom_ht26_r.git
cd scom_ht26_r

# Настройте переменные окружения
cp .env.example .env
# Отредактируйте .env, добавив ваш OPENROUTER_API_KEY

# Запустите проект
docker-compose up -d --build
```
